Components page audit

Every top-level frame on the 🧩 Components page, sorted into the tiers from Extending the system. Click a tile to filter; click a frame name to open it in Figma. Approve or change the tier, then the rebuild starts from Core.

CoreTier 1 — a system component. Gets a spec, semantic variables, package implementation.
CompositionTier 2 — built from core components + tokens. Lives in its feature namespace; leaves the Components page.
LocalTier 3 — feature-owned component. Tokens only, principles pass, briefed. Promote on third use.
AssetIcon or illustration. Move to an Assets page / icon library.
KeepDocumentation. Move to its own page.
HousekeepingRename, merge, move out, or delete.
