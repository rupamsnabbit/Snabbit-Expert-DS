Design tokens

The named values every Expert-app screen is built from. Use the semantic name, never the raw hex or dp, so a change here reaches every screen at once.

Color

Semantic colors

Pick by role — what the color does on screen — not by hue. Contrast is measured against bgPrimary (#FFFFFF) for text tokens.

Core palette
