Core component · composition

MapMarker · MapSnippet

The app does not navigate; it hands off to the phone's maps app, and that is right. What it owns is the moment before: a small muted map that shows where — the customer's home, the hub, the hotspot — and where she is, with one Button that opens directions. The pins are the message; the map is context.

One meaning each

Markers

A 32 dp head with a Phosphor glyph, a white ring so it reads on any tile, and a label pill — always. An unlabelled pin is a red pin. me is a blue dot with a halo (an arrow when heading is known; grey when the fix is stale); hotspot is a dashed circle, not a pin, because it is an area.

Tier 2

MapSnippet

Card with a static muted map (≤ 3 markers, fit to bounds, no controls), the address with an inline Listen, the distance line, and Show directions. Tapping the map does what the Button does. If the tile fails, the address and the job marker stand in and the Button still works.

tap a snippet
Behaviour

Rules

  1. Hand off, don't navigate. Directions open the phone's maps app with the destination pinned; walking mode under 1.5 km.
  2. Static. No pan, pinch or zoom controls; the snippet is one target.
  3. ≤ 3 markers: the destination, me, a hotspot when relevant. A list of jobs is a ListItem list, never a map.
  4. Labels always. When two labels collide, me yields; the destination never hides its label.
  5. Distance updates every 30 s while open: 3.2 km · about 12 min, rounded to 5 min, never seconds, never ETA. Time pressure belongs to the Timer.
  6. Map style is muted everywhere — greyscale roads, no POI labels, no traffic — so the markers are the only colour.

What changes in Figma

  1. Create MapMarker: Kind (Job / Hub / Me / Hotspot), Size (M / L), State (Default / Selected / Stale). Heads bound to bgBrand / bgInverse / textInfo.
  2. Create MapSnippet: Height (160 / 240), booleans Hotspot, Me; muted map placeholder; address + Listen + distance + Show directions.
  3. Replace the default red pins and the overlaid Show directions strip in the arrival and Home hotspot cards with the composition.

Result: ~10 variants, and the same pins on every map. Token proposal: map.style muted.
