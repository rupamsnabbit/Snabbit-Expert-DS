Core component

Card

A bounded surface that says "these belong together, and this is one thing to look at or tap." Boring on purpose: one shape, one border, no shadow, four slots. Everything interesting happens inside, using the other components.

ProposedTier 1 · CoreSnabbitCardradius lg · border thin · flatheader · media · body · footer
Structure

Anatomy & slots

Toggle slots to see the card rebuild itself. Padding 16, internal gap 12, 12 between cards, 16 screen margin. Cards live on a bgSecondary page so border and fill separate without a shadow.

How it's tapped

Kinds

Static, tappable (whole card, caret in the header), expandable (header toggles the body), empty (a dashed add slot). One tap target per card or many small ones — never both.

Behaviour

States

Loading is a skeleton of the real layout, never a spinner in a box. Error is an inline Banner as the first body child — the card itself doesn't go red. Pink border means selected, nothing else.

Built from parts

Compositions

The feature cards in Figma — earnings, job, metrics — rebuilt as Card + Amount + ListItem + Tag. Nothing here is drawn; it's all composed. Tap the earnings header to expand.

Reconciliation

What changes in Figma

  1. Cards – States → Card: Kind (Static / Tappable / Expandable / Empty), State (Default / Pressed / Selected / Disabled / Loading), slot booleans Header, Banded, Media, Footer, Footer buttons (1 / 2).
  2. Pink border exists only as Selected.
  3. Rebuild Earnings, Summary, Attendance, Job States, Navigation and Metric cards as Card instances with composed bodies; move them to feature pages.
  4. Delete every drop shadow.
  5. Bind border, fill, radius to tokens.
