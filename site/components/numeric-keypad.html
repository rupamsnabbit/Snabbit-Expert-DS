NumericKeypad

Every number she types — her phone, the OTP the customer reads out, an amount — goes through one in-app keypad: twelve big keys, digits only, the same size, place and sound on every phone. The OS keyboard shrinks, changes and carries letters she does not need.

Try it

Live

Type with the keypad. Phone: the Button enables at ten digits and the number is read back in groups of five. OTP: the sixth digit auto-submits (try 123456 — anything else is a wrong code and shakes). Amount: live ₹ grouping with a 00 key. Hold backspace to clear.

Behaviour

Rules

  1. Appears when a numeric TextField gains focus; 296 dp, anchored to the bottom, below the flow's Button; the entry always stays visible above.
  2. Every key: light haptic + the system key click; sound off → haptic only. Max length reached → the entry bumps, no digit, no error text.
  3. Backspace: tap removes one digit; hold 600 ms clears everything with a medium haptic. Never disabled.
  4. Read back (phone, amount): once complete, the digits are spoken in groups of five — "…is this right?" — before the Button acts. Not for OTP.
  5. Wrong OTP: shake, clear, Toast Wrong code — try again; after three, Resend code becomes primary.
  6. Never shown with the OS keyboard; dismissed by the Button, auto-submit, or tapping outside — never a hidden "done" key.
  7. Latin digits in all four languages — the digits on money, phones and clocks.
