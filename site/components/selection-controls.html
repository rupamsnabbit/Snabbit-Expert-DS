Core components

Checkbox · Radio · Switch

Three controls, one rulebook. They differ only in shape and what the shape promises: square means any number, circle means exactly one, pill means on or off — right now.

Choosing

Which one

Checkbox — several may apply

Services she can do, days she works, a single consent. Not for a yes/no that takes effect immediately — that's a Switch.

Radio — exactly one of 2–5

Shift length, language. More than 5 → a Select sheet. Options with a description, price or image → SelectionCard.

Switch — on/off, takes effect now

Available for jobs, notifications. Needs no Save. A costly switch-off (going offline mid-shift) opens a confirmation sheet first.

Anatomy

Shapes & states

Every state is carried by shape and glyph as well as colour. Checked is a filled square with a check; selected radio is a ring with a dot — the two never look alike. The switch knob carries an x or check so position and colour are never the only difference.

Try it

Live behaviour

Tap anywhere on a row. The switch applies optimistically, shows a spinner while "saving", and the costly one asks first.

Together

Groups & errors

Error belongs to the question, not to one box: on submit every unchosen control in the group gets the red border and one line below says what to do. Consent rows get a speaker so the full text can be heard.

Reconciliation

What changes in Figma

  1. Collapse three sizes to one 24 dp control inside a 48 dp row component with Label, Description and Leading icon slots.
  2. Selected → State; add Pressed; move Error to a Group component (rows + error line).
  3. Radio selected = ring + dot, not a filled circle.
  4. Add Switch: 52 × 32 track, 24 dp knob with x / check; Off / On / Disabled × 2 / Loading.
  5. Rebind to semantic variables; text to BodyLg / BodyMd.

Result: 16 row variants + 1 Group, replacing 33 control-only variants.
