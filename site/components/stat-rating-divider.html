Stat · Rating · Divider

Three small things on almost every screen, so they must be exactly the same everywhere: a number with its name, how the customer felt — as faces, not stars — and the line between things.

ProposedTier 1 · CoreSnabbitStat · SnabbitRating · SnabbitDividerLabel above valueFaces, not stars
A number with its name

Stat

Label first, value second — she reads the name before the number. Values follow the Amount rules. A delta appears only when the comparison is one she can act on (vs last week), coloured and arrowed. At most four Stats in a Card, 2 × 2 with a Divider between rows.

How did it go?

Rating

Input: five faces from the illustration layer, 48 dp; tap one and its word appears and is spoken. Display: a number to one decimal and one face for its band — never five tiny stars. Under five ratings the display says New.

How was the job?
 
tap a face
The line between things

Divider

1 dp, never thicker, never decoration. row inset 16 dp between ListItems; section full-bleed with 16 dp space; labelled to group a list by day or status. Never two in a row, never under a heading or above a Button, never where a Card edge already divides.

What changes in Figma

  1. Value + Metric Card → Stat: Size (S / M / L), Delta, Icon; label above value in every variant.
  2. Rating → Rating: Form (Input / Display), Value (1–5); five kept Smileys as instances; delete the other ten; display = number + one face.
  3. Create Divider: Kind (Row / Section / Labelled); replace every hand-drawn 1 dp line in the Lifecycle mocks.
  4. Table Components → ListItem + Stat S.

Result: ~14 variants replacing 38 frames.
