Core component

Avatar

A face in a circle. When reading is slow, a face is the fastest way to say who — so the avatar has to be reliable when there's no photo, honest about verification, and never used for anything that isn't a person.

Sizing

Sizes

Nine sizes become five, on the asset grid: 24 list meta · 32 rows and chat · 40 cards and header · 56 profile row and contest ranks · 96 profile hero and selfie confirm.

When there's no photo

Sources & fallback

Photo → initials → illustration → placeholder. A photo that fails falls to initials, not to the grey glyph. Initials get a colour from the name, so the same person is always the same colour.

Deterministic initials colour

Type a name — same name, same wash, every time. Six washes, text in the 700 step.
Two facts about a person

Status & verified

Who is available and who is verified. The dot has a 2 dp white ring so it reads on any photo; the verified mark is Phosphor seal-check filled. Status colour is never alone — the name row always says it in words too.
