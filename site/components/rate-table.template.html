  • Three value columns or fewer. A fourth condition is a second table; 58 dp cannot hold ₹149 to 175/hr.
  • Never horizontal scroll. At font scale 1.3 the table re-flows to one ListItem per row with the values stacked in the description.
  • Read row by row, with the column name repeated: Work — Monday to Friday ₹120 an hour, Saturday ₹130, Sunday ₹130.
  • No colour in a cell. A higher rate is not a status.
