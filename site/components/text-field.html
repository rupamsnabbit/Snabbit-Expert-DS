Core component

TextField

One component for everything the expert types. Five Figma frames become one field with a kind — same label, border, error and helper everywhere, so learning one means learning all.

ProposedTier 1 · CoreSnabbitTextField7 kinds × 2 sizes × 7 statesReplaces 5 frames
One component

Kinds

Every kind shares the same anatomy: label above (always visible), 56 dp field, optional leading Phosphor icon, one trailing slot, helper line below at 14 sp. Search is the only kind allowed without a label — its icon and placement are the label.

Behaviour

States

Error is carried by three channels — border, icon, message — and appears on blur or submit, never on every keystroke. Verified data is read-only until Change is tapped.

Try it

Live behaviour

Real inputs. Phone formats as you type and validates on blur; OTP auto-advances and shakes on a wrong code (try anything except 123456); the counter tracks the note.

Reconciliation

What changes in Figma

  1. Merge Input field, Mobile and OTP, Number Input, Text Box, Search Box into one component with Kind, Size, State, and booleans for leading icon and helper.
  2. Field height 56 (L) / 48 (M), radius 12, padding 16.
  3. Disabled: grey the Change action and drop the verified check.
  4. Helper and error to BodyMd; error line gets x-circle.
  5. OTP: Boxes 4 / 6; add error and filled states; Resend as a ghost Button in the helper.
  6. Rebind to semantic variables.
