Core component

Tag

Labels a thing with its status or category. Read, not tapped — anything tappable that looks like a tag is a Chip or an XS Button.

ProposedTier 1 · CoreSnabbitTag6 tones × 3 styles × 3 sizesNot interactive
Meaning × emphasis

Tones × styles

Tone is meaning — success is done or paid, warning is waiting, error is failed or penalised, info is a fact to notice, brand is new, neutral is a category. Soft is the default; solid is for the one status that must dominate a card. Warning · solid fails contrast and is not allowed.

  • Purple is gone. It isn't in the palette; if it meant tier, tier is TierBadge.
  • Status tags carry an icon. Colour alone never carries meaning (P1).
  • At most two tags per card, one solid.

What changes in Figma

  1. Delete the purple set. Color → Tone (Brand / Neutral / Success / Warning / Error / Info); Style → Solid / Soft / Outline.
  2. Four sizes → L / M / S; delete the duplicate 12 sp row.
