Emphasis × meaning

Variants × tones

A variant is how much the action matters on this screen. A tone is what kind of action it is. Greyed cells are combinations that are not allowed — nothing neutral is ever the one next action, and danger is filled only inside a confirmation sheet.

  • Success is not a variant. Green is a status colour; a green button makes the action look like a result (P6).
  • Link is not a button. Inline text links become a small Link component.
  • Icon on one side only. Leading says what the action is; trailing only for direction (P1).

Behaviour

States

Five states, and a hold gesture for anything that loses the expert money or a job. Try them — these are live.

Live behaviour

Loading keeps the label

Tap once. The spinner takes the icon slot, the label stays, further taps are ignored until it clears (P5).

Hold to confirm (danger)

Press and hold 600 ms. Let go early and nothing happens. Completing changes the label to the outcome (P3).

Duplicate-tap guard

Tap as fast as you can. Only one click registers per 300 ms.

Reconciliation

What changes in Figma

  1. Rename Style → Variant (Primary / Secondary / Tertiary / Ghost); add Tone (Brand / Neutral / Danger). Delete Success, Link, Neutral Filled, Neutral Stroke, Text.
  2. State: add Pressed, Focused, Loading; add a Hold boolean on Danger.
  3. Content: delete Icon Both.
  4. Rebind every fill, stroke and text colour to semantic variables; text styles to ButtonLg / ButtonMd.
  5. Disabled: bgTertiary fill + textTertiary label instead of the pink-200 wash.
  6. Move Button Groups, Progress Buttons, Block/Unblock off the Components page.

Result: ~90 variants instead of 294.
