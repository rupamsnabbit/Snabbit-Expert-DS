Core components

Badge

"Badge" means two different things in the Figma file and in every design system. This page splits them: a tiny count or dot pinned to something else, and the metallic hexagon she earned.

ProposedTier 1 · CoreSnabbitBadgeSnabbitAchievementBadgeFigma "Badge – Parent" → AchievementBadge
Badge

A nudge to look

Count or dot on the corner of an IconButton, tab, avatar or card. Information, never a target. Clears the moment the thing is seen.

AchievementBadge

A thing she earned

A reward-layer asset (metallic hex) with a size, a state and a label. The artwork comes only from the asset register; the component only places it.

Part 1

Badge — count · dot

Pinned top-right with a 2 dp white ring so it separates from any host. Count ≤ 9 then 9+ — two digits is the most she should read at 12 sp in a corner. Prefer the dot: fewer digits, same information.

On a tab bar

Discipline

Badge rules

  • One badge per host, three badged hosts per screen (tab bar included). More is noise, not nudging — P6 says nudges are rare.
  • Never success tone. A badge asks her to look; a finished thing needs no nudge.
  • Never money. An amount is an Amount.
  • Clears when seen. A badge that lingers trains her to ignore badges.
  • Announced with the host: "Chat, 3 unread". A dot announces "new".
Part 2

AchievementBadge

Four sizes, five states. A locked badge is greyscale with a lock and a label saying how to earn it — a grey hexagon alone is a mystery, not motivation. Tap Earn it to see the ≤ 1.5 s celebration.

Reconciliation

What changes in Figma

  1. Rename Badge – Parent → AchievementBadge: Asset (swap from Assets page), Size (24 / 40 / 64 / 96), State (Earned / Locked / In progress / Just earned / Equipped), boolean Label.
  2. Create Badge: Kind (Dot / Count), Tone (Brand / Error / Neutral), Count. Nest into IconButton, BottomTabBar item, Avatar.
  3. Badges Groups → a composition on the profile pattern, not a component.
  4. Bind fills to semantic variables; count to Caption SemiBold.

Result: Badge 6 · AchievementBadge 20 (asset swapped, not multiplied).
