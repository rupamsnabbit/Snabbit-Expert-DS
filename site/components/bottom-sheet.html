Core component

BottomSheet

The only modal surface in the app. It rises from where the thumb already is; a centred box in the middle of the screen reads as "something broke". The confirmation Dialog, the Select menu, the Permission sheet and short forms all live on it.

One shell, five jobs

Kinds

Info tells; confirm asks and cannot be dismissed by accident; select lists; form takes one input; permission explains why before the OS asks. Same padding, radius, title and action rules on all five.

From the Button spec

Action rules

  • Stacked, full width, L. The primary or most-likely action is lowest — nearest the thumb.
  • Costly = secondary danger + hold. Losing earnings, a penalty, logout mid-shift, blocking a customer. Never a filled red button, never one tap.
  • Side by side only in confirm, only when both outcomes are legitimate and equal (Absent / Present) — both secondary neutral, safer on the left, neither coloured.
  • No Yes / No / Okay. Go offline · Stay available · Start job · Allow camera · Not now.
  • Never three actions.
  • Confirm has no ✕, no drag, scrim tap does nothing, back = the safe option.

What changes in Figma

  1. Merge the 15 sheets into BottomSheet: Kind (Info / Confirm / Select / Form / Permission), booleans Hero, Grabber, Close, Facts strip, Secondary action.
  2. Close ✕ moves inside the sheet, top-right, IconButton M ghost; removed on Confirm.
  3. Green / red / status buttons → Button instances per the action rules; No | Yes → stacked verbs; Absent | Present → two secondary neutral.
  4. Costly confirms (Emergency logout, Block, Lose earnings) → secondary danger + Hold.
  5. Illustrations → asset instances; delete stray 1825:6967.
  6. Rebuild the 15 sheets as instances on their feature pages.

Result: ~20 core variants; 15 feature sheets become compositions.
