## What the reads changed in the project

- **Q10 corrected:** the Expert ID + OTP handshake already runs in the PRD's direction in every current file. What is undrawn is the *rotation* (life, refresh), her photo on the card, and Home placement.
- **Order:** no shipped file has the contactless order. Shipped TC-less puts the Hub before Aadhaar (v2) or training before go-live with *Start working* at the end (v2 training). The contactless order is a third order and is drawn, not inherited (Q8).
- **Permissions:** every file ships the bare OS dialog; the "existing design" the PRD wants kept is s3a/s3b (pictogram + one button). Design problem 1 is confirmed by evidence, and Mobbin supplies the denied-path convention and the drawn-settings-row idea.
- **Training home** has two newer shapes (rail + grid; Accordion + rings) than `onboarding.md` § 6a. The variant section must choose; the fail screen and lockout are compositions to design.
- **New asks of core** from the reads: a `guide` per maker (already ask 2); MediaCapture `document` tips as a pictogram row; a Profile *Permissions* page composition; a Profile row for certificate / kit record; `empty-state.md` has no neutral `info` kind (surface 2, 10 use `empty` anatomy).
- **New open questions:** the loose *Language preference* sub-flow in Self-Serve (reading test, *more pictures and voice*, hear Saathi per language) is in no PRD or pattern; OTP box count (4 shipped vs 6 spec); one word for the per-module check (*Knowledge check* / *Assessment* / *quiz*).
- **Strings never to reuse** (seen in the files): *Taking u there*, *I machines witch on and work*, *Payment didnt go through*, *Marati*, *Koramangla*, *Try restarting the app*, *We are not hiring male experts at the moment*, *Full Time / Part Time / Smart Shift*, *Micromarket*, emoji coin pills.
