## The pattern

1. **One number that grows.** Nobody shows months on the main surface. The waiting money is a *balance*; it just gets bigger.
2. **The breakdown is a plain table.** Hero total on top, then label · amount rows. No title restating it, no sentence, no Total row (the hero *is* the total).
3. **Long lists fold.** Lloyds folds 15 payments into one line; old periods sit in history, one tap away (*See activity*).
4. **The action is one button**, separate from the number.
