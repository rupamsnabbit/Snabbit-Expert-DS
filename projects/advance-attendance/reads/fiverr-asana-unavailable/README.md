# Fiverr — Availability · Asana — Show me as away (Mobbin, iOS, read 2026-10-01)

Source: https://mobbin.com/flows/f9230f7b-0ce5-4807-a125-a23b43ba594e · https://mobbin.com/flows/c23b51aa-8d3b-4259-87e9-49602d05b93f

1. **Idea.** Nobody is asked whether they are available. Available is the default; the person states the exception (*Set unavailable dates*, *Show me as away*) and sees it listed afterwards with an edit.
2. **Idea vs skin.** Borrowable: **exception-only**, the default stated plainly, the exception shown back as a row she can edit. Skin: paragraphs explaining consequences, a date-range form, a toggle plus two date fields.
3. **Against the expert.** The idea is the lightest possible ask — zero taps on a normal day. It fails P5 only if the default is hidden; so the default must be *shown* (Present on every shift), not implied.
4. **Tier.** Nothing new: the record on Home is a Card; the exception is a tap on a shift.
